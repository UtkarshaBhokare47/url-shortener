# URL Shortener

A simple URL Shortener API built using FastAPI and SQLite.

## Features

- Create short URLs
- Redirect using short URLs
- View all URLs
- Update URLs
- Delete URLs

## Technologies

- Python
- FastAPI
- SQLite
- Uvicorn

## How to Run

Install dependencies:

    pip install -r requirements.txt

Run the application:

    uvicorn main:app --reload

Then open:

    http://127.0.0.1:8000
